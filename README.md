# orbit-transfer-lab

An interactive web application that models ideal Hohmann orbital transfers between circular orbits around Earth, Mars, and the Moon.

## Features

-  Interactive mission planner
-  Earth, Mars, and Moon simulations
-  Delta-v calculations
-  Transfer time calculations
-  Orbital transfer visualization
-  Built with HTML, CSS, and JavaScript

## Physics

This project implements classical orbital mechanics concepts, including:

- Hohmann Transfer Orbits
- Vis-Viva Equation
- Circular Orbit Velocity
- Delta-v Analysis
- Orbital Transfer Time

## Technologies

- HTML5
- CSS3
- JavaScript
- Canvas API
